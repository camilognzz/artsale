# Landing Page para Plataforma de Arte Contemporáneo 

Este proyecto es una landing page diseñada para una plataforma de arte contemporáneo, desarrollada utilizando Next.js, NextUI, TypeScript, y Tailwind CSS. La página incluye una estructura moderna y modular, con componentes reutilizables para secciones como el encabezado, galería, artistas destacados, eventos, y contacto. Utiliza un diseño responsivo con colores suaves, tipografías elegantes y una experiencia visual atractiva que resalta las obras de arte y la información relevante.
